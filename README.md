# 果然 TV

一个给家庭电视、Android 盒子和安卓平板使用的轻量桌面。遥控器、鼠标、触屏均可操作，所有片单在同一页上下浏览。

**[下载 APK](https://github.com/voanit/guoran-tv/releases/latest)** · [全部版本](https://github.com/voanit/guoran-tv/releases) · [报告问题](https://github.com/voanit/guoran-tv/issues)

当前为 **0.5.3 试用版**。没有广告、账号服务器或付费解锁，不附带课程、网盘账号或视频资源。可先作为普通应用试用，系统允许时再手动设为默认桌面。

## 能做什么

- 自定义首页名称，新增、改名、排序片单和课程；首次安装为空白首页，没有固定的哥哥、妹妹栏目。
- 连接自己的百度网盘应用目录，首页自动展示主目录文件夹和视频；点文件夹逐级浏览，点视频直接播放。支持真实视频缩略图、最近播放和断点续播。
- 全盒子亮屏使用时间统一管理：默认连续 30 分钟休息 10 分钟，也可设置每日额度、允许时段、暂停和临时 PIN 解锁。
- 手机浏览器通过同一局域网管理内容、上传封面、开放已安装应用及上传 APK；安装仍需在设备上确认。
- 首页最下方集中展示家长开放的应用。家长 PIN 验证后可进入当贝市场、系统设置、缓存清理。
- 右下角小尺寸返回／首页导航支持鼠标拖动，内置视频播放时隐藏；遥控器使用标准方向键、确认、返回和 Home。
- 本地视频：原盒子可继续用自带文件管理器；其他设备优先使用 Android 系统文件选择器，无须整个存储权限。

## 安装与首次使用

1. 从上面的 Releases 下载 `.apk`，通过 U 盘、系统文件管理器或 ADB 安装。最低声明 Android 5.0。
2. 打开“果然 TV”。初始家长 PIN 为 **2580**，首次使用请在家长工具中修改。
3. 若需要鼠标跨应用返回和跨应用休息页，在系统无障碍设置里手动开启“果然 TV 鼠标导航”。Android 新版可能要求在应用信息中先允许受限设置；入口和限制以设备系统为准。
4. 在“家长管理 → 手机管理”查看当前 IP 和六位配对码。同一 Wi-Fi 的手机打开 `http://设备IP:8787`，配对后配置内容。
5. 需要替换桌面时进入“家长管理 → 系统设置 → 选择默认桌面”。厂商可能不开放第三方默认桌面选择；安装本身不会修改系统或卸载原桌面。

百度网盘、当贝市场及其他第三方应用不在 APK 内，不会随安装自动出现。请从各自官方渠道安装与设备兼容的版本，再用家长页开放应用。

### 自家百度网盘目录

1. 在[百度网盘开放平台](https://pan.baidu.com/union/)创建自己的应用，确认具备基础文件列表与下载权限。
2. 手机家长页填写自己的准确应用名称、AppKey 和 SecretKey，到百度官方页面授权自己的账号。
3. 把文件夹或视频放进「我的应用数据／你的应用名称」。该目录的第一层自动展示在首页，约每 60 秒同步，也可手动刷新；每页读取 100 项，更多内容支持翻页。
4. 如果希望某个目录单独出现在片单中，可通过网盘选择器选中后自行命名、上传封面。

不要求安装百度网盘客户端，不解析他人分享链，不调用付费流量或转码接口。可用权限、配额、速度和文件格式仍受百度平台及账号条件约束。本项目不提供共用 Key，不能替代接收者自己的应用配置。

### 本地文件与播放器

系统文件选择器支持本机和已挂载的 U 盘／SD 卡，实际可见位置由系统提供。选择视频后交给内置播放器；系统授予持久读取权限时可保留最近记录。临时内容提供器只保证本次播放，拔出存储后需要重新连接。

内置播放使用 Android `VideoView` 和系统解码器，建议 H.264 MP4。H.265、特殊音轨及高码率视频因机型而异，也可选择“其他播放器”。

## 兼容性与已知边界

| 环境 | 状态和边界 |
| --- | --- |
| Android 7 / miniH6 | 已真机安装，验证首页、网盘目录／播放、最近记录、遥控与鼠标操作、休息页 |
| Android 15 模拟器 | 已测试安装、横屏首页、触控家长入口及局域网管理；不等于所有平板实机通过 |
| 小米电视／小米盒子 | 已提供电视入口和通用文件选择回退，尚缺具体型号实机验收；安装和默认桌面权限受固件限制 |
| Android 平板 | 横屏布局，支持触屏；保留系统返回方式，具体解码和后台行为需目标设备验收 |
| iPad、非 Android 系统电视 | 无法安装此 APK |

Android 8+ 使用低打扰前台服务通知维持计时和家长管理。厂商省电、手动强停、关闭无障碍、关机等会影响能力；这不是设备所有者、反卸载或不可绕过的强管控方案。计时按整个设备亮屏使用，不按某个孩子或片单区分。

当前 `minSdk=21`、`targetSdk=28`、`compileSdk=34`，没有 JNI 或 CPU 专用库。较低 target 用于旧电视兼容，不代表已达到应用商店上架要求。手机管理当前只支持局域网，未提供异地隧道。建议先在目标机型试用，记录系统版本、解码和返回行为后再适配。

## 从源码构建

使用 Python 3、JDK 17+、Android SDK Platform 34 和 Build Tools 34.0.0，无 Gradle、无第三方运行库。当前脚本适合 macOS／Linux；Windows 可使用 WSL 或按同一 aapt/javac/D8 流程适配。

```sh
export ANDROID_SDK_ROOT=/你的/Android/Sdk
export JAVA_HOME=/你的/JDK17或更高版本
python3 build-debug.py
```

也可以显式指定工具路径：

```sh
python3 build-debug.py --sdk /你的/Android/Sdk --jdk /你的/JDK --javac /你的/javac
adb install -r guoran-tv-debug.apk
```

生成 `guoran-tv-debug.apk`。本机签名保存在忽略的 `.build/guoran-debug.keystore`，请自行备份，升级必须复用原签名。自行构建与 Releases 签名不同，不能直接相互覆盖安装；卸载会删除本地配置，请先评估数据保留。仓库不会提供签名私钥。

## 适配代码位置

| 文件 | 职责 |
| --- | --- |
| `MainActivity.java` | 首页／目录／播放器、遥控和触屏、系统文件选择、设置跳转 |
| `Store.java` | 家庭本地配置、片单迁移、应用名单、整机观看规则 |
| `BaiduDrive.java` | 官方授权、应用目录边界、缩略图及本机临时播放流 |
| `DeviceService.java` | 前台服务、每秒整机计时、局域网家长服务 |
| `MouseNavigationService.java` | 无障碍返回／首页、跨应用休息遮罩 |
| `ParentServer.java` | HTTP、手机配对、受控 APK 上传、局域网鉴权 |
| `app/src/main/assets/parent.*` | 手机家长页面 |

Java 路径均为 `app/src/main/java/cn/guoran/tv/`。修复特定机型时请优先使用系统 Intent 和标准权限，避免增加另一台盒子专用包名。提交 Issue 请附型号、Android 版本、操作步骤与已脱敏日志，勿附 Key、token、PIN、家庭配置或私有视频地址。

## 数据与权限

安装包只含代码与通用绘制资源。网盘 Key／Secret／token、家长 PIN、课程、自定义封面和播放历史仅在每台设备的应用私有目录生成；`allowBackup=false`。家长接口不回传密钥，视频临时地址只供本机使用。源码和 Releases 不含作者家庭数据，也不附第三方影视海报或视频。

权限用于联网、系统确认安装 APK、导航及前台服务。文件选择只授予选中的 URI，不申请全盘读写。无障碍服务不读取屏幕内容，不自动帮用户开权限。
